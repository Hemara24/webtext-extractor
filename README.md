# WebText Extractor

WebText Extractor is a Python-based tool that extracts and structures useful text from public web pages.

## Features

- Extract page title, headings, paragraphs, and links
- Clean unnecessary text
- Detect basic page types
- Save output as JSON
- Simple Streamlit interface

## Tech Stack

- Python
- Requests
- BeautifulSoup
- pandas
- Streamlit

## How to Run

```bash
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```

## Output

The application extracts website content and allows the user to download it as JSON.

## Disclaimer

This tool is intended for permitted public web content only. Users should respect website terms of service, privacy policies, and robots.txt rules.
